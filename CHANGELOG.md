# История версий

## v1.9.0 — 2026-10-01

- **Палитра стала светлее** (меньше тонера на чб-печати), а грани коробов — с более заметной, тёмной обводкой, чтобы короба не сливались друг с другом даже при близких оттенках.
- **Починена шеренга, вылезающая за рамку**: в двухколоночной раскладке «Шеренга 1 / Шеренга 2» строки были физически шире, чем помещается в половину страницы — колонки внутри шеренг сужены отдельно от пула (в пуле, где места больше, они остаются широкими).
- **Поля «Паллета / Шеренга» больше не «перескакивают» мгновенно** — клик по стрелочке применяется с небольшой задержкой (или сразу по Enter), чтобы успеть кликнуть/вписать оба поля перед тем, как строка переедет и перестроит экран.
- Клик в любое числовое поле строки теперь сразу выделяет всё значение — можно сразу печатать новое число, не стирая старое вручную.
- **Загрузка готовой раскладки убрана** — приложение принимает только исходный заказ (артикул + количество), вся раскладка по паллетам/шеренгам теперь всегда собирается внутри редактора.
- Excel и PDF при скачивании называются «Раскладка №‹заказ›» вместо имени исходного файла.

## v1.8.0 — 2026-09-25

- **Новая цветовая палитра артикулов** — вместо случайного цвета по хэшу артикула теперь фиксированный набор из 12 тонов, подобранных так, чтобы каждый давал свой уровень серого на чёрно-белой печати (проверено на реальной распечатке) — раньше некоторые артикулы сливались в почти одинаковый тёмный цвет на бумаге.
- **«Убрать» строку из шеренги больше не удаляет её из заказа** — теперь это просто возврат в «Не распределено» (с поддержкой Ctrl+Z), а не безвозвратное удаление. Из заказа вообще ничего нельзя удалить насовсем — только переместить.
- Кнопка «✂ Разделить» больше не исчезает, когда в строке 1 шт — теперь просто становится серой и неактивной, чтобы кнопки в строке не «прыгали».
- **Выгрузка в Excel переработана**: добавлены рамки таблицы и колонки «Паллета»/«Шеренга», убран вес (в UI он не нужен уже давно), названия колонок габаритов приведены к тем же, что в редакторе.
- На карточке паллеты в блоке «Состав заказа» добавлены габариты (Д×Ш×В) и высота столбика — раньше были только артикул и количество.
- **Дата отгрузки подставляется сама** — по умолчанию ближайшая пятница (поле остаётся обычным, можно поправить вручную).
- В настройках длинные подсказки под полями заменены на значок ⓘ рядом с названием — панель настроек стала компактнее.
- Тулбар редактора («Отменить», «Излишек», «Готово» и т.д.) собран в одну строку без переносов, подписи сокращены.
- Заголовки колонок в таблице редактора — теперь полными словами («ВЫСОТА», «ПАЛЛЕТА/ШЕРЕНГА») вместо сокращений, колонки расширены под них.

## v1.7.0 — 2026-09-23

- **Номер заказа подставляется сам** — если в имени загруженного файла есть «Заказ 12345678», поле «Заказ №» в настройках заполняется автоматически (только если оно было пустым).
- **Строка заголовков теперь и в каждой шеренге**, не только над «Не распределено» — колонки видно сразу у любого блока, без прокрутки наверх.
- Стрелочки-степперы вернул для полей «Паллета / Шеренга» — там быстрый ввод числа кнопками удобнее, чем для габаритов. У остальных числовых полей стрелочек по-прежнему нет.

## v1.6.0 — 2026-09-23

- **Строки редактора сузились в разы** — перешёл на CSS Grid с фиксированными узкими колонками вместо гибкой раскладки, из-за которой строки расползались за пределы окна.
- **Строка заголовков** над списком — теперь видно, что означает каждая колонка (Артикул, H, Кол-во, Д×Ш×В, Пал/Шер, Действия), и колонки реально выровнены между строками.
- **Убраны стрелочки-степперы** у числовых полей — они только отъедали ширину без пользы. Значения теперь вписываются вручную, поля стали заметно уже.
- **Вес убран из редактора** — для раскладки он не нужен. Не показывается на строке, не показывается на карточке (ни в шапке, ни в составе заказа). По-прежнему считается внутри и попадает в Excel-выгрузку — для совместимости с готовыми раскладками, которые можно снова загрузить в приложение.
- Сокращены отступы между элементами строки и внутренние поля — компактнее, но не слипается.
- Текст и значки внутри строки выровнены по центру — раньше «гуляли» по вертикали из-за разной высоты строки/иконок.

## v1.5.1 — 2026-09-22

- **Ctrl+Z починен**: раньше он не срабатывал, если фокус был в одном из числовых полей строки — а фокус там почти всегда, поля занимают большую часть строки. Теперь откатывает всегда, независимо от фокуса.
- Строка редактора теперь строго в одну линию: если не помещается по ширине — список едет вбок горизонтальным скроллом, а не переносится на вторую строку.
- Значки ✂/⇄/× заменены на единые SVG-иконки одного размера и толщины линии — раньше системные символы отрисовывались каждый по-своему и «гуляли» по размеру.
- Каждая строка теперь подсвечена тем же цветом, что артикул получит на самой паллете (цветная полоса слева + лёгкая тонировка фона) — легче сопоставить строку с конкретным коробом на карточке.

## v1.5.0 — 2026-09-22

Большой апдейт по удобству редактора:

- **Карточки → строки.** Вместо сетки квадратных карточек — компактный список строк, легче сканировать глазами большой заказ.
- **Быстрое назначение паллеты.** Вместо выпадающего списка на десятки пунктов — два маленьких поля «Паллета / Шеренга» прямо на строке (например «2/1»). 0 в поле паллеты — вернуть в пул. Если вписать номер паллеты больше, чем сейчас существует — недостающие паллеты создаются сами.
- **Высота столбика (H:)** теперь заметный цветной значок, а не мелкая серая подпись — это главный ориентир при ручной раскладке.
- Кнопки «Разделить»/«Поменять местами»/«Удалить» сокращены до значков ✂ / ⇄ / ×.
- **Выгрузка в Excel** — кнопка «Скачать Excel» в редакторе и на экране готовых карточек: таблица итогового распределения в том же формате, что и готовая раскладка (такой файл можно снова загрузить в это же приложение).

## v1.4.0 — 2026-09-18

- **Отмена действий** — кнопка «↶ Отменить» в редакторе и Ctrl+Z: откатывает перенос, разбивку, своп, удаление, правку любого поля — можно нажимать много раз подряд.
- **Лимит по количеству коробов**: общее число коробов артикула не может превысить то, что было в заказе. Если вписать в поле количества число больше текущего, недостающее автоматически заберётся из другой строки того же артикула. Переключатель «Излишек →» решает откуда/куда: в нераспределённый остаток или в другую шеренгу, где этот артикул уже есть.

## v1.3.2 — 2026-09-18

Нашёл и починил причину, по которой перетаскивание карточек стало ненадёжным: карточка плотно набита полями ввода и кнопками, а клик по ним внутри перетаскиваемого блока перехватывает начало жеста раньше, чем браузер успевает распознать drag — в реальности он просто не стартовал в большинстве мест карточки. Добавил отдельную «ручку» (⠿) слева от названия артикула — тянуть теперь нужно строго за неё, остальная часть карточки (поля, кнопки, выпадающий список) работает как обычно и не мешает.

## v1.3.1 — 2026-09-18

Переосмыслил кнопку «Начать заново» → «Сбросить изменения»: раньше она стирала файл из истории целиком, что было неожиданно. Теперь она просто отменяет все правки и возвращает раскладку к состоянию сразу после загрузки файла — сам файл остаётся в истории, редактор не закрывается. Удалить файл из истории насовсем по-прежнему можно из самой «Истории файлов» (кнопка «× Удалить» на нужной записи).

## v1.3.0 — 2026-09-18

- Подсветка при перетаскивании теперь охватывает весь блок «Не распределено»/шеренги целиком, а не подгоняется под размер уже лежащих внутри карточек.
- Новая кнопка **«История файлов»**: каждый загруженный файл (и заказ, и готовая раскладка) сохраняется в этом браузере — можно вернуться к любому из них позже, не пересохраняя файл. Черновик заказа в истории обновляется автоматически по мере редактирования. Можно удалить отдельную запись или очистить историю целиком.

## v1.2.1 — 2026-09-17

Убрал задержки при перетаскивании/переносе карточек в редакторе. Причина была в двух местах:
- Редактор пересчитывал превью **всех** паллет на каждое действие, а не только той, которую поменяли — добавил кэш по паллете, пересчитывается только реально изменившаяся.
- Сам пересчёт картинки (~200 мс на паллету) выполнялся синхронно и блокировал интерфейс — теперь он уходит на следующий тик, интерфейс откликается сразу, а изображение подтягивается через мгновение (пока считается — показывает предыдущий кадр приглушённым).

Замерил: время, которое реально «подвешивает» интерфейс на одно действие, упало с ~700–1200 мс до ~100–150 мс на документе с 20 паллетами.

## v1.2.0 — 2026-09-17

- Переключатель «Порядок в шеренге: авто / вручную». Авто (по умолчанию) — как раньше, короба сами расставляются по высоте столбика от края к центру. Вручную — можно перетащить карточку прямо на другую внутри шеренги, чтобы вставить её до или после (по тому, на какую половину карточки навели), порядок задаёте сами.
- Убрал мигание подсветки при перетаскивании карточки над соседними карточками внутри области — теперь подсветка держится ровно, пока курсор внутри зоны.

## v1.1.1 — 2026-09-17

- Поле веса на карточке артикула в редакторе — расширил, значение больше не обрезается.
- На карточке теперь виден расчёт «H:» (высота столбика) — это главный ориентир при ручной раскладке.
- Список «Не распределено» после загрузки заказа сразу сортируется по высоте столбика, от большего к меньшему.

## v1.1.0 — 2026-09-17

Большое обновление: теперь можно собирать раскладку не только из готового файла, но и с нуля — из голого заказа (артикул + количество) и таблицы-справочника габаритов.

- Приложение само определяет тип загруженного файла: если в нём нет колонок габаритов — это заказ, и открывается редактор раскладки.
- Справочник габаритов подтягивается напрямую из Google Таблицы (экспорт в TSV, без ключей и входа в аккаунт), ссылка настраивается. Количество из заказа делится на «Кол-во, шт OUTER» из справочника — получается число коробов.
- Редактор: артикулы — карточки-«чипы», которые можно перетащить или переместить через выпадающий список в любую шеренгу любой паллеты, разделить количество на две части (✂), поменять местами длину и высоту (⇄ Д/В) — то же самое, что раньше делалось руками в Excel. Габариты/вес/количество можно поправить прямо на карточке.
- Живой предпросмотр каждой паллеты обновляется сразу при любом изменении.
- Черновик редактора автоматически сохраняется в браузере — обновление страницы работу не стирает.
- Важное ограничение браузеров: подключение к Google Таблице работает только когда страница открыта по ссылке (http/https); при запуске локального файла двойным кликом (file://) браузер блокирует такой запрос по CORS — при этом привычная работа с готовыми файлами раскладки офлайн не затронута.

## v1.0.0 — 2026-09-17

Первый публичный релиз.

- Раскладка коробов по паллетам из Excel — полностью в браузере, без установки.
- Карточка паллеты: вид сверху, два изометрических ракурса, профиль высот, состав заказа.
