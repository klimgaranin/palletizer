# История версий

## v1.4.0 — 2026-09-18

- **Отмена действий** — кнопка «↶ Отменить» в редакторе и Ctrl+Z: откатывает перенос, разбивку, своп, удаление, правку любого поля — можно нажимать много раз подряд.
- **Лимит по количеству коробов**: общее число коробов артикула не может превысить то, что было в заказе. Если вписать в поле количества число больше текущего, недостающее автоматически заберётся из другой строки того же артикула. Переключатель «Излишек →» решает откуда/куда: в нераспределённый остаток или в другую шеренгу, где этот артикул уже есть.

## v1.3.2 — 2026-09-18

Нашёл и починил причину, по которой перетаскивание карточек стало ненадёжным: карточка плотно набита полями ввода и кнопками, а клик по ним внутри перетаскиваемого блока перехватывает начало жеста раньше, чем браузер успевает распознать drag — в реальности он просто не стартовал в большинстве мест карточки. Добавил отдельную «ручку» (⠿) слева от названия артикула — тянуть теперь нужно строго за неё, остальная часть карточки (поля, кнопки, выпадающий список) работает как обычно и не мешает.

## v1.3.1 — 2026-09-18

Переосмыслил кнопку «Начать заново» → «Сбросить изменения»: раньше она стирала файл из истории целиком, что было неожиданно. Теперь она просто отменяет все правки и возвращает раскладку к состоянию сразу после загрузки файла — сам файл остаётся в истории, редактор не закрывается. Удалить файл из истории насовсем по-прежнему можно из самой «Истории файлов» (кнопка «× Удалить» на нужной записи).

## v1.3.0 — 2026-09-18

- Подсветка при перетаскивании теперь охватывает весь блок «Не распределено»/шеренги целиком, а не подгоняется под размер уже лежащих внутри карточек.
- Новая кнопка **«История файлов»**: каждый загруженный файл (и заказ, и готовая раскладка) сохраняется в этом браузере — можно вернуться к любому из них позже, не пересохраняя файл. Черновик заказа в истории обновляется автоматически по мере редактирования. Можно удалить отдельную запись или очистить историю целиком.

## v1.2.1 — 2026-09-17

Убрал задержки при перетаскивании/переносе карточек в редакторе. Причина была в двух местах:
- Редактор пересчитывал превью **всех** паллет на каждое действие, а не только той, которую поменяли — добавил кэш по паллете, пересчитывается только реально изменившаяся.
- Сам пересчёт картинки (~200 мс на паллету) выполнялся синхронно и блокировал интерфейс — теперь он уходит на следующий тик, интерфейс откликается сразу, а изображение подтягивается через мгновение (пока считается — показывает предыдущий кадр приглушённым).

Замерил: время, которое реально «подвешивает» интерфейс на одно действие, упало с ~700–1200 мс до ~100–150 мс на документе с 20 паллетами.

## v1.2.0 — 2026-09-17

- Переключатель «Порядок в шеренге: авто / вручную». Авто (по умолчанию) — как раньше, короба сами расставляются по высоте столбика от края к центру. Вручную — можно перетащить карточку прямо на другую внутри шеренги, чтобы вставить её до или после (по тому, на какую половину карточки навели), порядок задаёте сами.
- Убрал мигание подсветки при перетаскивании карточки над соседними карточками внутри области — теперь подсветка держится ровно, пока курсор внутри зоны.

## v1.1.1 — 2026-09-17

- Поле веса на карточке артикула в редакторе — расширил, значение больше не обрезается.
- На карточке теперь виден расчёт «H:» (высота столбика) — это главный ориентир при ручной раскладке.
- Список «Не распределено» после загрузки заказа сразу сортируется по высоте столбика, от большего к меньшему.

## v1.1.0 — 2026-09-17

Большое обновление: теперь можно собирать раскладку не только из готового файла, но и с нуля — из голого заказа (артикул + количество) и таблицы-справочника габаритов.

- Приложение само определяет тип загруженного файла: если в нём нет колонок габаритов — это заказ, и открывается редактор раскладки.
- Справочник габаритов подтягивается напрямую из Google Таблицы (экспорт в TSV, без ключей и входа в аккаунт), ссылка настраивается. Количество из заказа делится на «Кол-во, шт OUTER» из справочника — получается число коробов.
- Редактор: артикулы — карточки-«чипы», которые можно перетащить или переместить через выпадающий список в любую шеренгу любой паллеты, разделить количество на две части (✂), поменять местами длину и высоту (⇄ Д/В) — то же самое, что раньше делалось руками в Excel. Габариты/вес/количество можно поправить прямо на карточке.
- Живой предпросмотр каждой паллеты обновляется сразу при любом изменении.
- Черновик редактора автоматически сохраняется в браузере — обновление страницы работу не стирает.
- Важное ограничение браузеров: подключение к Google Таблице работает только когда страница открыта по ссылке (http/https); при запуске локального файла двойным кликом (file://) браузер блокирует такой запрос по CORS — при этом привычная работа с готовыми файлами раскладки офлайн не затронута.

## v1.0.0 — 2026-09-17

Первый публичный релиз.

- Раскладка коробов по паллетам из Excel — полностью в браузере, без установки.
- Карточка паллеты: вид сверху, два изометрических ракурса, профиль высот, состав заказа.

- Встроенная справка с описанием формата таблицы и бизнес-правил раскладки.
